# Agent Swarm Lab

Infinite improvement loop - 6 agents working in sequence.

## Agents

1. Analyst - Find what's broken
2. Architect - Design solution
3. Builder - Implement code
4. Reviewer - Check quality
5. Optimizer - Enhance beyond requirements
6. Deployer - Validate and save

## Loop

Analyst -> Architect -> Builder -> Reviewer -> Optimizer -> Deployer -> (repeat)

## Usage

export NVIDIA_API_KEY=your-key
python run.py "Your project idea"
